# ResourceHacker-zh_CN

把经典资源修改工具 Resource Hacker 汉化成简体中文。

## 简介

Resource Hacker 是一款查看、修改、提取 Windows 可执行文件资源的工具，原版功能强大但界面全是英文，对中文用户不太友好。本汉化版把菜单、对话框、提示信息全部翻译成简体中文，用起来更顺手。

## 功能

- 查看和编辑 EXE、DLL、OCX、SCR 等 PE 文件中的资源
- 替换图标、位图、光标
- 修改菜单和对话框布局
- 编辑字符串表和版本信息
- 提取资源到文件
- 重新编译修改后的资源并保存回原文件
- 作为资源编译器，把 .rc 脚本编译成 .res 文件

## 使用

1. 下载本仓库代码
2. 解压后运行 ResourceHacker.exe
3. 打开要修改的 EXE 或 DLL 文件
4. 在左侧树中选择资源类型，右侧编辑内容
5. 修改完成后点「编译脚本」再保存
