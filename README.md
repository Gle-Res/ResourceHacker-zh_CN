# ResourceHacker-zh_CN
Resource Hacker是轻量化 Windows 资源修改工具，支持 EXE、DLL、MUI 等主流 PE 文件，实现资源查看、提取、编辑与重新编译。可处理图标、位图、菜单、对话框、字符串、版本信息等内容，多用于软件汉化、界面美化、版本修改、逆向学习。本仓库为 ResourceHacker 汉化版本，基于原版程序仅做界面汉化，不改动核心解析逻辑。适配 Windows系统，程序小巧纯净无捆绑，保留原版 GUI 图形界面与命令行模式，依旧支持批量自动化资源处理。汉化仅方便国内用户阅读操作，相关版权归原作者所有。本工具仅限用于个人学习以及修改自身拥有权限的程序，禁止未经授权篡改第三方闭源商用软件，使用者自行承担全部责任。如遇到显示问题、程序异常，欢迎提交反馈。100
